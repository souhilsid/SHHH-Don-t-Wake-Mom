# Trailer Remotion source (copy)

The live, editable project is `SHHH/Remotion` (Remotion 4.0.544, installed deps). These are copies of the trailer files for the archive.

- `ShhhTrailer.tsx` - picture track (shots with slow top-anchored push-ins, phrase cards, logo reveal). Silent by design.
- `trailer_timeline.json` - generated by `../build_trailer_timeline.py` (edit THAT, then re-run it; it also cuts the shot proxies
  into `SHHH/Remotion/public/trailer/`).
- `Root.tsx` - registers `ShhhTrailer` and `WalkthroughCard`.

Re-render:
```
cd SHHH/Remotion
npx remotion studio src/remotion/index.ts          # preview / tweak
npx remotion render src/remotion/index.ts ShhhTrailer ../VideoProduction/07_Trailer/Renders/trailer_picture_v1.mp4 --muted --codec=h264 --crf=14 --concurrency=4
cd ../VideoProduction/07_Trailer
../Tools/tts_venv/Scripts/python -I mix_trailer_audio.py   # stems + master + .srt
bash mux_trailer.sh                                         # final MP4 in 09_FinalExports
```
