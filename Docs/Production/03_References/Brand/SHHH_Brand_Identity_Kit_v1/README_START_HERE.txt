IMPORTANT: SVG file types
- TRUE_VECTOR files are path-based shapes with editable contours. The full-color version is a multi-color automatic TRACE, not semantic hand-drawn letters. Colors and curves approximate the raster.
- SHHH_Exact_Look_PNG_Embedded.svg is a bitmap wrapper and cannot be meaningfully edited as vector geometry.
- SHHH_Editable_Font_Layout.svg uses editable text requiring separately installed Luckiest Guy and Fredoka fonts; it does not replace the approved artwork.
