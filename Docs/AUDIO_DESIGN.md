# AUDIO DESIGN
- 70 original clips generated by `Tools/synth_audio.py` (22.05 kHz mono; Vorbis in build): impact_{ceramic,glass,metal,wood,plastic,toy,appliance,soft,fabric,paper}×4, squeak×3, UI (click/hover/step/chore/grab/trap/countdown), mom_snore loop, mom_babble×4, mom_wake_stinger, door creak/close, dog bark×3/huff, cat meow×2, amb_night loop (crickets, wind, clock), music_menu (original music-box lullaby), win/elim stingers.
- Buses: SFX, Voice, Music (menu only, can be disabled), Ambience, UI — independent volumes in Settings.
- Spatial 3D for all world sounds (log rolloff 0.6–18 m). Silence + Foley drive tension; no music during rounds.
- Mom's English lines are in `MomLines.cs` and shown as subtitles; the voice is a placeholder babble (marked TEMPORARY) until an authorized TTS or recorded English VO is approved.
- Voice chat (planned Photon Voice) is fully separate from gameplay noise.
